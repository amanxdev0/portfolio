## Run it

No build step — just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Enable GitHub Pages on this repo to take it live: Settings → Pages → Deploy from branch → `main` / root.

## Notes

- Images are embedded as data URIs (`assets/img*.js`) so the whole site ships as text files.
- Contact form uses EmailJS (CDN).
